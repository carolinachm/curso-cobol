# Desafios e Exercícios

A pasta de desafios e exercícios reúne programas mais completos, com foco no uso prático dos comandos estudados.

## O que está em cada diretório

### Exercícios

A pasta de exercícios guarda programas menores, com propósitos didáticos e etapas simples.

- [exercicios/ola-carolina.cbl](../exercicios/ola-carolina.cbl): primeiro exemplo com várias linhas exibidas na tela. Esse programa trabalha com `DISPLAY` repetido e mensagens simples.
- [exercicios/aula-02-sistema.cbl](../exercicios/aula-02-sistema.cbl): demonstra a montagem de uma tela com cabeçalho, cliente, conta e saldo.
- [exercicios/aula-03-funcionario.cbl](../exercicios/aula-03-funcionario.cbl): introduz a ideia de registro com campos como matrícula, nome, idade, cargo e salário.
- [exercicios/aula-03/produto.cbl](../exercicios/aula-03/produto.cbl): segue o mesmo padrão do cadastro de funcionário, porém com dados de produto.

### Desafios

A pasta de desafios guarda programas com um nível maior de necessidade visual e organização.

- [desafios/desafio-01.cbl](../desafios/desafio-01.cbl): mostra um layout com cadastro e a identidade do estagiário.
- [desafios/desafio-02.cbl](../desafios/desafio-02.cbl): apresenta um mini-menu com cabeçalho, banco e operações do sistema.

## Aprendizados com a prática

Esses arquivos ajudam a entender:

- como dividir uma saída em várias linhas;
- como usar `PIC` para reservar espaço;
- como preencher textos com `MOVE`;
- como organizar um layout visual com `DISPLAY`;
- como construir um pequeno cadastro com campos em grupo.

## Caminho de aprendizagem

A sequência relevante do curso é:

1. aprender a imprimir uma linha com `DISPLAY`;
2. declarar campos com `PIC` em `WORKING-STORAGE`;
3. carregar esses campos com `MOVE`;
4. montar uma tela com regras visuais;
5. compor um registro com vários elementos.
